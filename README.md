# ИрискИ — Frontend

## Технологии

- **React** — построение пользовательского интерфейса.
- **TypeScript** — типизация кода.
- **Vite** — запуск и сборка приложения.
- **ESLint** — статическая проверка кода.
- **Prettier** — единое форматирование.

## Структура проекта

```text
src/
├── api/             # Запросы к backend
├── components/
│   ├── layout/      # Общие элементы интерфейса (шапка)
│   ├── deal/        # Форма параметров сделки
│   └── risk/        # Результаты расчёта и объяснения
├── pages/           # Страницы приложения
├── types/           # Общие TypeScript-типы
├── utils/           # Вспомогательные функции
├── App.tsx          # Корневой компонент
└── main.tsx
```

## Запуск проекта

Требуется Node.js и npm.

```bash
npm install
npm run dev
```

## Проверка и сборка

```bash
npm run lint
npm run format:check
npm run build
```

Для автоматического форматирования:

```bash
npm run format
```
