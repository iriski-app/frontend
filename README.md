# ИрискИ — Frontend

Frontend веб-приложения **«ИрискИ»** для оценки финансовых рисков сделок с облигациями. Пользователь может указать параметры сделки, получить информацию об инструменте и просмотреть результат расчёта риск-метрики DV01.

## Технологии

- **React** — построение пользовательского интерфейса.
- **TypeScript** — типизация данных и компонентов.
- **Vite** — запуск и сборка приложения.
- **CSS** — стилизация интерфейса и адаптивная вёрстка.
- **Vitest** — модульное тестирование.
- **React Testing Library** — тестирование React-компонентов.
- **jsdom** — браузерное окружение для тестов.
- **ESLint** — статическая проверка кода.
- **Prettier** — форматирование кода.

## Запуск проекта

Требуются Node.js и npm.

```bash
npm install
npm run dev
```

После запуска Vite выведет адрес локального сервера разработки.

### Режим демонстрационных данных

Для разработки интерфейса без запущенного backend можно создать файл `.env.local` в корне проекта:

```env
VITE_USE_MOCK_API=true
```

В этом режиме используются демонстрационные данные облигации и фиксированный тестовый результат расчёта риска.

Для работы с backend:

```env
VITE_USE_MOCK_API=false
```

Базовый путь API по умолчанию — `/api/v1`. При необходимости его можно переопределить через `VITE_API_BASE_URL`.

## Основная функциональность

### Реализовано

- Форма параметров одиночной сделки: ISIN облигации, направление покупки/продажи и количество.
- Валидация ISIN, включая проверку контрольной цифры.
- Проверка положительного целого количества облигаций.
- Сегментированный переключатель направления сделки и поле количества с кнопками увеличения и уменьшения.
- Получение информации об облигации через API или mock-данные.
- Отображение характеристик инструмента и доступных рыночных данных.
- Отправка запроса на расчёт риска.
- Отображение итоговой DV01 в рублях.
- Обработка состояний загрузки, успешного ответа и ошибок.
- Сброс устаревшего результата при изменении параметров сделки.
- Адаптивная вёрстка с плавным изменением пропорций карточек формы и результата.

### Интеграция с backend

HTTP-клиент использует `credentials: 'include'` для поддержки сессионных cookie.

Расчёт риска выполняется запросом:

```http
POST /api/v1/risk-calculations
```

Параметры передаются в массиве `positions`, включая расчёт одиночной сделки:

```json
{
  "positions": [
    {
      "isin": "RU000A100006",
      "side": "buy",
      "quantity": 10
    }
  ]
}
```

Frontend типизирован под DTO расчёта backend, включая `id`, `status`, `as_of_date`, `total_dv01_rub` и массив результатов `positions`.

Фактическое взаимодействие с Go backend находится на этапе интеграции.

## Тестирование

Настроены Vitest, React Testing Library и jsdom.

Реализованы автоматические тесты:

- Валидация ISIN.
- Валидация количества облигаций.
- HTTP-клиент: GET и POST, отправка cookie, обработка HTTP-ответов и ошибок соединения.
- Проверка работоспособности тестового окружения React.

Запуск всех тестов:

```bash
npm run test
```

Тесты выполняются без необходимости запускать backend.
